ARIN 320 · UNIT 5 · AI LAB SPRINT

AI USE STATEMENT

This sprint was built with an AI coding assistant, Claude (made by Anthropic), running in Claude Code. I came up with the project and directed it. The AI wrote the code. Here is who did what.

What I did

  • Picked Unit 5 and the two formats: a video-game version of the Triage Desk sprint, and a two-team quiz show where teams type their own names.
  • Set the design through my requests: characters to pick, leveling up, getting stronger, voices that read the text aloud, and a way for students to prove their AI scores.
  • Playtested both games, flagged problems (such as how students and the instructor verify Comprehend scores), and asked for fixes.
  • Chose where to host the games and published them here.

What the AI did

PartHow AI was used
CodeThe AI wrote the HTML, CSS, and JavaScript for both games and this site: the clinic map, movement, levels, scoring, boss fight, quiz board, and print-to-PDF report. It also tested the games in a browser and fixed the bugs it found.
ImagesNo image generator was used. The AI drew every character, the clinic, the robot, and the boss as pixel art written directly in code.
VoicesNo AI voice clips were made. The voices are the speech engine built into the web browser (the same voices that read text aloud in Windows and Chrome). The AI wrote the code that gives each character its own voice, pitch, and speed.
TextThe AI drafted the game text, quiz questions, and answers from the Unit 5 Guide (Parts 1 and 2) and the existing Triage Desk sprint. The answers follow the Guide’s own wording.

The prompts I used

Characters and images. What I asked for when I turned the sprint into a game:

“make it look and feel like an actual video game. pick characters, level up, learn and get stronger. etc.”

The AI turned this into four pixel-art classes (Triage Nurse, Data Analyst, Pharmacist, Red Teamer), a walkable clinic, a robot called the Machine, and the Complaints Queue boss, all drawn in code.

Voices in the RPG.

“Can you use AI to give each character a voice to read so we do not read text it reads it for us?”

The AI gave each character its own browser voice: Dana reads the instructions, patients read their messages, the Machine reads the AI’s output, and the boss and each class have their own voices.

Voices in the quiz show. I asked for one voice to read each question and another to read the correct answer. My first request named two famous TV personalities. The AI would not imitate real people’s voices, so the game uses two original voices instead: a narrator for the questions and a host for the answers.

Why this matters for Unit 5

Unit 5 is about reading what AI hands you and deciding who checks it before anyone acts. The same rule applied here. The AI produced the code and the text, and a person reviewed and tested what it made before it went to students.
